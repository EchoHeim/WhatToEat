## 一次性订阅的真实规则（2026-10-28 查证，以后别再记错）
官方社区 2025 Q&A（https://developers.weixin.qq.com/community/develop/article/doc/00024292b700589d04c37999d66813 ）：
- **2.2 用户一天内点 N 次订阅，就能发 N 条通知** —— 次数**累加**，不是"一次授权终身一条"。
- **2.3 每次订阅获得的下发机会永久有效**，不按天过期。
- **2.1 勾选「总是保持以上选择，不再询问」只是不再弹窗**，用户不点按钮仍然不会增加次数；点了按钮（哪怕不弹窗）照样 +1。
- 所以"额度 > 0 就能持续推送"是**对的**，直到额度耗尽。额度记账（`pushQuota`）与微信侧次数基本一致：点一次 `requestSubscribeMessage` +1，云函数 `send` 成功 -1，`43101` 归零。
- 第 3 条文案已改为：「攒下的额度永久有效、不会过期；推送会出现在微信的「服务通知」里。」

### 关键坑：Skyline 的 `<button>` 忽略 width / flex:none
页内对照实验（同一行并排放 A/B/C）：`button` + `width:120rpx` + `display:flex` → 仍占约半行；`button` + `width:120rpx` + `line-height` → 也占半行；`view` + `width:120rpx` → 正常。

## 20:35 修「底部标签点了没反应」——Skyline 下 custom-tab-bar 的命中区陷阱

**根因（实测定位）**：把胶囊改成 `position: static` 后截图，它跑到了**页面顶部**。说明 Skyline 里自定义 tabBar 组件的宿主节点排在页面原点，`position: fixed` 只改了绘制位置、没改命中区 —— 点击全落到屏幕顶部那条看不见的区域，所以四个标签都「没反应」。和 16:35 那条 `absolute` 画一处点一处是同一个毛病。

**改法：悬浮条不再放在 custom-tab-bar 组件里，改由各 tab 页自己渲染**
- `templates/tabbar.wxml`：定义 `<template name="app-tabbar">`，四个 `.app-tab` 带 `bindtap="onTabTap"`、`hover-class` 按下反馈。
- `styles/tabbar.wxss`：胶囊样式（`position: fixed`，class 前缀 `app-`）。
- `utils/tabbar.js`：`LIST` / `create(selected)` / `go(e)`（`wx.switchTab`）。
- 四个 tab 页：wxml 顶部 `<import src="/templates/tabbar.wxml" />`、底部 `<template is="app-tabbar" data="{{...tabbar}}" />`，wxss 首行 `@import "../../styles/tabbar.wxss";`，js 里 `tabbar: tabbar.create(n)` + `onTabTap(e) { tabbar.go(e) }`。原来是页内 `getTabBar().setData({selected})` 的那几行全删了（每个页面自己一份 selected，天然不会错位）。
- `custom-tab-bar/` 缩成 0 尺寸占位（`custom: true` 时框架找不到目录会编译失败）。
- **模板传参必须是 `data="{{...tabbar}}"`**：写成 `data="{{tabbar}}"` 时模板作用域里只有 `tabbar` 这个名字，`wx:for="{{list}}"` 取不到东西 —— 第一版胶囊渲染出来是空壳（只有底色没有图标文字），就是这个原因。

## 00:05 摇骰落定加「撕开礼包」彩带迸射

`handlePick` 摇骰结束的那一刻（`this.pick({ celebrate: true })`）在结果卡片里放 22 片彩带，从菜品中心向四周迸射、飞出卡片后淡出。`preview/2026-10-28/burst-final.png` 是模拟器实拍。

**Skyline 上连踩三个坑，记下来别再走一遍**：
1. **内联 `animation-*` 会让动画整个不播**——只要 `style="...; animation-delay: 45ms"` 出现在节点上，这条元素就只剩 `opacity:0`（此时节点在渲染树里能查到，`$$('.confetti-bit')` 数得出 22 个，但屏幕上什么都没有）。把 delay 挪进样式表后立刻正常。结论：**动画属性一律写在 wxss，内联只放 left/top/width/height/background**。
2. **多层嵌套的「旋转臂 + 碎片」画不出来**：`绝对定位容器 → 旋转臂(420rpx 方块, ±210rpx 负边距) → 碎片` 这种结构在 Skyline 下完全不渲染。最后改成单层：22 个碎片直接做卡片的绝对定位子节点，方向靠 12 个固定角度类 `d1~d12`（每类一条 keyframes，视觉上够用）。
3. **`.lottery-orbit` 的虚线圆在 Skyline 里画成方块**（`border: dashed` + `border-radius: 50%` 不裁圆），摇骰动画里那个旋转方框就是它。还没改，要改得换成小圆点排布。
