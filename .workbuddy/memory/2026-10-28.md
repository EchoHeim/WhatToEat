# 2026-10-28

## 「我的」页底部版本号（Ver0.0.2）

- 需求：在 `pages/profile` 最下方显示版本号，当前 Ver0.0.2。
- 实现：
  - `pages/profile/profile.js` data 新增 `appVersion: 'Ver0.0.2'`（单点维护，以后改版本只改这一行）。
  - `pages/profile/profile.wxml`：删掉原 scroll-view 内的 `今天吃什么 · 本地体验版 1.0`，改为 scroll-view **外面**的 `<view class="version-bar">今天吃什么 · {{appVersion}}</view>`。
  - `pages/profile/profile.wxss`：新增 `.version-bar { flex: none; padding: 16rpx 0 20rpx; text-align: center; color:#ACA89F; font-size:20rpx; }`，`.profile-page` padding-bottom 60→24rpx。
- 为什么放 scroll-view 外：Skyline 下 scroll 内容容器高度是 auto，`min-height: 100%` + `margin-top: auto` 推底不可靠；page 本身是 `height:100vh; flex-direction:column`，`.page-scroll` 是 `flex:1`，所以第三个 flex 子元素 `flex:none` 就是稳定贴底方案。这是本项目第一个「scroll-view 外放元素」的页面，其余页面（含按钮）都是放在 scroll 内容里。
- 验证：`cli preview --project` 编译通过（包 154.1 KB）；三套测试全过。
