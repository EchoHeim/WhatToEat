## 提审被驳回：反馈页「联系方式」踩了运营规范 5.12

lodge 贴了两张图：意见反馈页 + 审核失败详情。

**驳回原文**：存在平台未允许的服务内容，违反《微信小程序平台运营规范 5.12》——
「涉嫌在非合理场景下收集、存储用户密码或个人敏感信息，包括但不限于微信帐号、QQ 号、银行账号等」。

**根因**：`pages/feedback/feedback.wxml` 的输入框 label 是「联系方式」，placeholder 写的是
**「微信号 / 邮箱，方便回访」**。审核是照着这行字判的——文案里出现「微信号」就够，标了「选填」也没用。

### 整改（只收邮箱，账号类词一个不留）

- `pages/feedback/feedback.wxml`：字段改「邮箱 · 选填 · 只用来回信」，placeholder「留一个的话，需要时按这个回复你」，maxlength 40→60；页脚补「邮箱也只用来回信」
- `pages/feedback/feedback.js`：`contact` → `email`，`contactChange` → `emailChange`，成功弹窗文案改「留了邮箱的话，需要时按那个地址回你」
- `cloudfunctions/feedbackSubmit/index.js`：`CONTACT_LIMIT` → `EMAIL_LIMIT = 60`，落库字段 `contact` → `email`，企微/飞书通知里的「联系方式」→「邮箱」；常量上方写了注释，说明为什么不能再加回来
- `utils/version.js`：`Ver0.0.9` → `Ver0.0.10`，`cli upload -v 0.0.10` 已同步
- `README.md` 意见反馈一节：写明「只收邮箱，不要改成微信号 / QQ 号 / 手机号」及被驳回的经过
